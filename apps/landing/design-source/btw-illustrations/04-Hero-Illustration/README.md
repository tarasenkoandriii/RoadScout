# Hero Illustration — v2.1

Обновлённый набор hero-иллюстраций «Beyond the Wall»: рука держит телефон,
который сканирует пространство и обнаруживает камеры поблизости. Все файлы
построены на единой канонической геометрии и токенах дизайна из
`BTW SVG Engineering Specification v4.0`.

## Состав

```
hero/
  hero.svg           1200x900  master — основная композиция
  hero-desktop.svg   1600x900  16:9   — широкие десктоп-вьюпорты
  hero-wide.svg      2160x900  2.4:1  — ультраширокие баннеры
  hero-square.svg     900x900  1:1    — соцсети / превью
  hero-mobile.svg     750x1000 3:4    — портретная мобильная раскладка
components/
  Phone.svg
  Hand.svg
  ScanCone.svg
  CameraMarker.svg
  CameraFOV.svg
preview/
  hero-dark.png      1200x900  hero.svg на его собственном тёмном фоне
  hero-light.png     1296x996  hero.svg в контексте светлой страницы (с отступом)
manifest/
  hero.json
README.md
```

`preview/` — растровые PNG для быстрого просмотра без открытия SVG (в
дизайн-тулах, таск-трекерах, чатах). Это не альтернативная светлая
цветовая тема иллюстрации — токен `bg` (`#0F172A`) зафиксирован намеренно
(см. `DesignRules` в 05-Icons и раздел «Токены» ниже), фон самой
иллюстрации не меняется. `hero-light.png` показывает тот же hero.svg,
просто оформленный на белой подложке — так удобнее проверить, как ассет
будет смотреться на светлой секции лендинга.

## Что нового по сравнению с v1

- **hero.svg** полностью пересобран: добавлены двухслойный scan-cone (глубина
  свечения), UI-детали на экране телефона (скан-линии + индикатор активности),
  переработанная кисть руки (запястье, большой палец поверх экрана, три
  пальца на обратной стороне корпуса вместо разрозненных линий), силуэт
  городского скайлайна на фоне (только токен `neutral`, `opacity 0.06`,
  чтобы не нарушать список разрешённых цветов) и pulse-кольца вокруг
  маркеров камер.
- Добавлены 4 адаптивных варианта (`mobile`, `desktop`, `wide`, `square`).
  `desktop`/`wide` — это master-композиция на более широком холсте
  (композиция центрируется, скайлайн достраивается по краям). `square` —
  прямой кроп master-канваса (тот же контент, другой `viewBox`). `mobile` —
  самостоятельная раскладка: телефон и рука остаются в исходном масштабе,
  кластер камер и scan-cone пересчитаны так, чтобы поместиться в портретный
  кадр без обрезки конуса.
- Компоненты `Phone`, `Hand`, `ScanCone`, `CameraMarker`, `CameraFOV`
  обновлены и приведены в соответствие с параметрами из раздела 5 ТЗ
  (см. комментарии в начале каждого файла).

## Каноническая геометрия (кадр 1200×900)

| Элемент       | Значение                                              |
|---------------|--------------------------------------------------------|
| Phone         | x=280 y=420 w=160 h=320 rx=24, screenPadding=12         |
| Scan origin   | (360, 420)                                              |
| Scan cone     | angle=80°, radius=520, start=-40°, end=+40°             |
| camera-1      | (610, 280) — success                                    |
| camera-2      | (760, 360) — warning                                    |
| camera-3      | (540, 170) — success                                    |
| Camera marker | 28×28                                                    |
| Camera FOV    | angle=24°, length=110, stroke-width=2                   |

Угол во всех формулах отсчитывается от направления «вверх»
(0° = вверх, по часовой стрелке положительный):
`x = originX + r·sin(θ)`, `y = originY − r·cos(θ)`.

## Токены дизайна

```json
{
  "grid": 8,
  "stroke": { "default": 4, "fov": 2 },
  "radius": { "sm": 8, "md": 16, "lg": 24 },
  "colors": {
    "bg": "#0F172A",
    "primary": "#3B82F6",
    "success": "#22C55E",
    "warning": "#EAB308",
    "neutral": "#F8FAFC"
  }
}
```

Ни один файл не использует цветов вне этого списка (декоративные слои —
скайлайн, pulse-кольца, второй слой scan-cone — используют те же токены с
пониженной непрозрачностью).

## Стабильные ID

`background`, `skyline`, `scan-cone`, `hand`, `phone`, `screen`,
`camera-1`, `camera-2`, `camera-3`,
`camera-fov-1`, `camera-fov-2`, `camera-fov-3`.

`skyline` и `hand` как ID групп — расширение поверх списка из раздела 7 ТЗ
(в каноническом гео-документе iteration 0 `hand` уже присутствует в списке
именования). Дубликатов ID нет ни в одном файле.

## SVG API

Каждый файл содержит `viewBox`, `width`, `height`, `role="img"`,
`aria-hidden="true"`. Максимальная вложенность групп — 2. Запрещённые
элементы (`filter`, `image`, `script`) не используются нигде.

## Использование компонентов (React-маппинг)

```jsx
<HeroIllustration />      {/* hero/hero.svg */}
<PrivacyIllustration />
<CameraMarker x={610} y={280} color="success" type="circle" />
<ScanCone originX={520} originY={520} radius={520} startAngle={-40} endAngle={40} />
```

Компоненты в `components/` — самостоятельные `.svg` со своим `viewBox` и
задокументированными параметрами (см. комментарий в начале каждого файла).
`CameraMarker.svg` по умолчанию рендерит `type="circle"`; альтернативный
контур для `type="drop"` приведён в комментарии внутри файла.
