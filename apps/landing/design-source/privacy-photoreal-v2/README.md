За прямим запитом користувача privacy-ілюстрацію замінено з плоского SVG на фотореалістичну
5-кроковий потік (камера → AI на пристрої → лише геометрія → зашифровано → користувач).

`privacy-source-original.png` — вихідний файл від користувача, 1536×1024, без обробки.
Контент займає майже всю ширину (0-1498px), але має значні порожні поля згори/знизу
(80px/160px) — desktop/mobile похідні обрізані саме під реальні межі контенту (1518×824),
без апскейлу.

Композиція горизонтальна (5 елементів в ряд) — НЕ підходить для портретної/квадратної
обрізки без втрати кроків потоку; секцію на сторінці змінено на full-width замість
двоколонкового макета саме через це.
