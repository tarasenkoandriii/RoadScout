`../btw-illustrations/04-Hero-Illustration/`) на фотореалістичну ізометричну сцену.

LANCZOS-ресемплінг (найякісніший класичний алгоритм; справжній AI-апскейл недоступний у
пісочниці збірки без мережі — обґрунтування в `doc/AUDIT-landing-v2-scope.md`).

Якщо колись знадобиться перегенерувати похідні розміри — використати саме
`hero-source-original.png` як джерело, не будь-який із уже обрізаних варіантів.
